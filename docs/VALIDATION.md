# 验证记录

## v0.2.0 · 2026-11-02

- 仓库已按用户要求改为公开。
- Release 构建通过，零警告、零错误；28 项核心检查通过，包括新增的 10 项任务栏位置检查。
- 位置检查覆盖：默认水平及垂直居中、水平位移不改变高度、两端边界限制、负坐标显示器、小尺寸任务栏、隐藏及竖直任务栏保护、无效配置恢复和屏幕尺寸变化。
- 移除系统自由拖动，歌词窗口只采样鼠标 X 坐标；Top 仅由任务栏中心计算，垂直方向没有拖动状态或保存配置。
- 通过 WPF RenderTargetBitmap 实际渲染三页设置界面和 840×660 紧凑窗口，检查灰阶、控件可读性、圆角、滚动条和内容排版。界面截图使用明确标注的模拟数据，不读取音乐客户端。
- 再次创建设置窗口通过，未复现先前的逻辑父元素复用异常。
- 实际鼠标拖动和真实播放器的端到端同步尚待人工验收；本轮未控制其他桌面应用。

## v0.1.0

日期：2026-11-02。环境：Windows x64，.NET SDK 8.0.427。

- Release 构建通过，零警告、零错误。
- 18 项核心检查通过，覆盖 LRC 多时间戳、小数精度、全局偏移、空歌词、前后跳转和边界、歌手及录音版本匹配、本地导入优先级及无时间戳文件拒绝。
- 在线冒烟验证成功：QQ 音乐的《晴天》／周杰伦，通过 QQ 接口取得 63 行带时间戳歌词；网易云的《成全》／林宥嘉，通过网易接口取得 79 行；Apple Music 路径以《Hello》／Adele 元数据匹配 LRCLIB，取得 48 行。验证只记录来源和行数，不提交第三方歌词内容。
- 网易云搜索《晴天》未提供满足歌手和时长的结果，程序通过 LRCLIB 回退成功，未选用搜索结果中的翻唱版本。
- 已生成 Windows x64 自包含便携程序和 ZIP，启动后可检测到设置窗口；SMTC 诊断可运行，本机当时没有活跃音乐媒体会话。
- 桌面交互验证由用户按 Esc 中止。运行日志发现并修复了关闭后重新打开设置时复用 TextBlock 的逻辑父元素异常；修复后的包重新编译通过，未完成后续交互复测。

尚待实机验收：QQ／网易云／Apple Music 真实客户端分别播放、暂停、继续、切歌、拖动进度，两个播放器同时运行时的优先级，DPI 变化、任务栏自动隐藏、全屏和多屏。接口请求成功不等同于上述播放器端到端验收完成。

重跑核心验证：`dotnet run --project tests/TaskbarLyrics.Tests -c Release`。

重跑在线验证：`dotnet run --project tests/TaskbarLyrics.Tests -c Release -- --smoke`。在线验证取决于上游网络和歌词可用性，成功缓存会显示“缓存”字样。
