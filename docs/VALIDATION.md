# 验证记录

## v0.3.1 · 2026-11-08

- 修复 Apple Music Windows 将“歌手 — 专辑”重复写入 Artist 和 AlbumArtist、AlbumTitle 为空时的歌词匹配。限制在 Apple Music 来源及已观测的带空格长破折号格式；不拆普通连字符，遇到冲突专辑/歌手或多重歧义分隔时保留原字段。
- 新增 11 项元数据检查，总计 35 项核心检查通过；设置读写与 17 项设置页检查通过。
- 真实 Apple Music 会话 `AppleInc.AppleMusicWin_nzyj5cx40ttqa!App` 播放方大同《麦恩莉》时，原始两个歌手字段均为“方大同 — 回到未来”，专辑为空；修复后恢复歌手“方大同”、专辑“回到未来”，匹配 LRCLIB 69 行同步歌词。
- 只读连续采样期间播放器报告正在播放，进度约从 160.75 秒推进至 169.56 秒，对应歌词索引从 42 推进至 43。未主动改变播放器播放状态或进度，未保存歌词正文。
- 修复版以真实媒体会话启动，任务栏窗口两次采样均可见，边界为 (482, 1388)–(1132, 1431)；间隔 5 秒的两幅窗口画面显示不同歌词行，已人工检查。检查后正常关闭测试实例，截图不随项目保留。
- 此证据确认该实际歌曲的元数据恢复、歌词获取和进度定位，尚不代表所有 Apple Music 曲目及暂停、切歌、拖动均已通过。

## v0.3.0 · 2026-11-03

- 24 项核心检查通过，新增设置草稿与托盘修改合并、其他歌曲校准保留、数值边界及无修改保存检查。
- 17 项原生设置页检查通过，包括窗口复用、取消不写入、保存失败保留草稿、切歌保留各自校准、操作回调、窄窗口滚动、键盘聚焦滚动及固定保存按钮。
- 保存按钮在 100%／125%／150%／200% 模拟 DPI 下均位于窗口可见区域；本机实际显示缩放为 150%。
- 已检查浅色、深色、播放信息页、关于页和紧凑窗口预览。所有截图使用明确标注的模拟歌曲，不读取真实播放器或修改正式设置。
- 设置页保持原生标题栏和系统窗口行为，歌词栏继续使用透明背景、图标避让及固定任务栏高度。

## v0.2.0 · 2026-11-03

- C++ 构建通过，使用 MSVC x64、`/W4 /WX`、静态运行库。
- 20 项核心检查通过，覆盖 8 项 LRC 解析与定位、5 项任务栏布局、7 项偏好行为，包括单曲隔离、全局叠加、范围限制、重置、暂停隐藏及复制边界。
- Unicode 歌曲标识、单曲校准与显示开关的 JSON 原子保存及重新读取通过，CI 和本机均执行；测试不修改正式设置。
- 本机 150% 缩放下，离线演示实际窗口检查通过，窗口为 605 × 51 物理像素，位于任务栏内且未与检测到的按钮重叠。
- 窗口透明色键有效，鼠标穿透可启用和关闭；模拟暂停后窗口隐藏，定时刷新不使其误显示，恢复播放后重新显示。
- GitHub Actions 构建及检查记录：[功能提交 de667bf](https://github.com/SaturdayF/taskbar-lyrics/actions/runs/41585981075)。

## v0.1.2 · 2026-11-03

- 原生程序通过 LRCLIB 在线查询公开样例 Hello / Adele 与 Super Star / S.H.E，分别取得 48 行和 35 行同步歌词；未将第三方歌词正文提交到仓库。
- 任务栏内演示窗口创建、响应、图标避让和退出检查通过；透明色键已验证。
- Apple Music 路径采用同专辑候选优先，并校验歌名、歌手和可用时长；播放器时间戳缺失时按本地进度补偿。

## 验证边界

窗口交互检查采用离线模拟歌曲；v0.3.1 另有上述 Apple Music 实际播放采样。QQ 音乐、网易云音乐以及 Apple Music 的暂停、切歌、进度拖动仍需逐一实机验收。网络样例验证不代表真实客户端端到端兼容性已确认。

双屏热插拔、混合 DPI、任务栏自动隐藏、替代任务栏和不同系统版本仍需进一步测试。窗口检查需在有可读任务栏空闲区的实际 Windows 桌面运行。
